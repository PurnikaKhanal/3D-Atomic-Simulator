# 3D Sphere Rendering with Lambertian Shading

### 📌 Project Description
This project demonstrates **3D sphere rendering** using the **Lambertian (Diffuse) Lighting Model** in C with the `graphics.h` library.  
The program calculates per-pixel lighting using surface normals and light direction vectors, then applies **ambient and diffuse reflection** to produce realistic shading.

### 🎯 Objective
- Implement Lambertian light shading.
- Understand surface normal computation.
- Simulate 3D lighting using mathematical calculations.
- Apply ambient and diffuse reflection for realistic shading.

### ⚙️ Key Features
- Per-pixel lighting computation.
- Sphere generated mathematically using x² + y² + z² = r².
- Uses normalized vectors for accurate lighting.
- Red sphere represents a proton (for atomic nucleus simulation).

### 🖥️ Requirements
- graphics.h library (BGI).
